# Мобильное приложение: Контроль домашней аптечки и сроков годности медикаментов (Вариант 11)

Курсовой проект / Комплект лабораторных работ по дисциплине мобильной разработки.

## 📋 Описание проекта
Приложение предназначено для учета лекарственных препаратов в домашней аптечке. 
Основные возможности:
1. **Каталогизация и просмотр (Главный экран):** Отображение списка лекарств, сортировка и фильтрация по форме выпуска («таблетки», «сиропы»).
2. **Управление данными (CRUD):** Полный цикл добавления, редактирования и удаления записей.
3. **Автоматизированное добавление (Mock-сканер):** Имитация сканирования названия препарата с упаковки с помощью камеры устройства.
4. **Реактивная проверка безопасности (Логика потоков):** При добавлении препарата его название автоматически сверяется со статическим JSON-справочником несовместимости действующих веществ. При обнаружении конфликта система блокирует добавление и выдает предупреждение.
5. **Локальное хранение:** Сохранение данных пользователя между сессиями (через `SharedPreferences`).
